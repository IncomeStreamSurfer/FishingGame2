CUMBIASCAPE - Cumbia Music Folder
=====================================

This folder contains all the cumbia music files for:
1. CumbiaBand - The 7-piece cumbia band that walks around the Jungle Realm
2. DockRadio - The radio on the jungle dock

HOW TO USE:
-----------
1. Place your cumbia music files (.mp3, .ogg, .wav) in this folder
2. Unity will automatically import them as AudioClips
3. Both the CumbiaBand and DockRadio will load ALL songs from this folder

CURRENT STATUS:
---------------
- This folder is currently empty
- The scripts will fallback to loading all songs from the Resources root folder
- To use ONLY cumbia songs, place your music files here

NOTES:
------
- CumbiaBand plays songs in RANDOM/SHUFFLE order
- Music does NOT auto-play - press F to start the band
- DockRadio plays CUMBIASCAPE songs instead of default radio songs
- Both systems support multiple song formats (mp3, ogg, wav)
