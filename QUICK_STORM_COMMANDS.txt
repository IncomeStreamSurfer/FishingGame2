╔══════════════════════════════════════════════════════════════╗
║                        WHAT TO VERIFY                        ║
╚══════════════════════════════════════════════════════════════╝

VISUAL EFFECTS
 □ Sky darkens during storm
 □ Sun dims to 30%
 □ Random white flashes (visual lightning)
 □ Full white flash when struck

AUDIO EFFECTS
 □ Deep rolling thunder (continuous)
 □ Heavy rain sounds (continuous)
 □ Sharp lightning crack when struck
 □ Distant thunder after visual flashes

UI ELEMENTS
 □ "THUNDERSTORM (XXs)" at top of screen
 □ "Storm approaching..." notification
 □ "Storm passing..." notification
 □ Lightning warning box appears
 □ "ZAP! You're fried..." death message

GAMEPLAY MECHANICS
 □ Lightning only strikes on dock/bridge
 □ 2-second warning before strike
 □ Warning cancels if you reach land
 □ Strike = instant death
 □ Normal respawn after death

╔══════════════════════════════════════════════════════════════╗
║               TROUBLESHOOTING QUICK FIXES                    ║
╚══════════════════════════════════════════════════════════════╝

CONSOLE WON'T OPEN
→ Try all three keys: ~, F1, F12
→ Check ConsoleCommands exists in Hierarchy
→ Make sure you're in Play mode

STORM WON'T START
→ Error: "ThunderstormSystem not found"
→ Fix: Check scene has ThunderstormSystem GameObject

TIME WON'T CHANGE
→ Error: "DayNightCycle not found"
→ Fix: Check scene has DayNightCycle system

COMMAND NOT RECOGNIZED
→ Type: help
→ Check spelling of command
→ Use Up arrow to recall last command
